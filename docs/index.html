Claude Codeを、
もっと直感的に。

Necodeは、Claude Codeに特化したデスクトップエディタ。
複数セッション、ファイル編集、チャットを
ひとつのワークスペースにまとめました。

macOS (Apple Silicon) macOS (Intel) Windows (.exe) Linux (.deb)

macOS 10.15以降 · Apple Silicon / Intel対応 · Claude Codeのインストールが必要です

Features

主な機能

エンジニアも非エンジニアも、
Claude Codeの力を最大限に引き出すための機能。

>_

複数セッション

最大4つのClaude Codeセッションを同時実行。2x2グリッドで並べて作業できます。

</>

内蔵エディタ

Monaco Editorでコードを直接編集。生成されたファイルをクリックひとつで開けます。

~

チャットモード

CLIとチャット表示をワンクリック切替。CLIに不慣れでも直感的に操作できます。

@

ファイル参照

画像やファイルをドラッグ&ドロップ。@メンションでワークスペース内のファイルを即参照。

/

スキル & MCP

登録済みのスキルやMCPサーバーを一覧で管理。ワンクリックで実行・ON/OFF切替。

#

MDプレビュー

Notionライクなプレビュー。編集モードと切り替えながらドキュメントを仕上げられます。

Getting Started

はじめ方

3ステップですぐに使えます。

1

Claude Codeをインストール

npm install -g @anthropic-ai/claude-code でCLIをインストールしてください。

2

Necodeをダウンロード

アクセスコードを入力して、お使いのOS用のインストーラーをダウンロード。

3

ワークスペースを選んで開始

Necodeを起動してフォルダを選択。「+ New」をクリックするとClaude Codeが立ち上がります。
