Claude Codeを、
もっと直感的に。

Necodeは、Claude Codeに特化したデスクトップエディタ。
複数セッション、ファイル編集、チャットを
ひとつのワークスペースにまとめました。

macOS版をダウンロード Windows 準備中 ソースコード

macOS 10.15以降 · Apple Silicon / Intel対応 · Claude Codeのインストールが必要です

Features

主な機能

エンジニアも非エンジニアも、
Claude Codeの力を最大限に引き出すための機能。

>_

複数セッションを同時実行

最大4つのClaude Codeを同時に動かせます。2x2のグリッドで全体を見渡しながら作業。

</>

エディタを内蔵

Monaco Editorでコードを直接編集。CLIが生成したファイルをクリックひとつで開けます。

💬

チャットモード

CLI表示とチャット表示をワンクリックで切替。CLIに慣れていなくても直感的に操作可能。

📎

ドラッグ&ドロップ

画像やファイルをチャットにドロップ。@でワークスペース内のファイルをすぐに参照。

⚡

スキル & MCP管理

登録済みのスキルやMCPサーバーを一覧で確認。ワンクリックで実行・ON/OFF切替。

📖

Markdownプレビュー

Notionのような見やすいプレビュー。編集とプレビューを切り替えながらドキュメントを作成。

Getting Started

はじめ方

3ステップですぐに使えます。

1

Claude Codeをインストール

npm install -g @anthropic-ai/claude-code でCLIをインストールしてください。

2

Necodeをダウンロード

上のボタンからDMGをダウンロードし、Applicationsフォルダにドラッグ。

3

ワークスペースを選んで開始

Necodeを起動してフォルダを選択。「+ New」をクリックするとClaude Codeが立ち上がります。
