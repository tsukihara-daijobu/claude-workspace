Necode

Claude Codeに特化したデスクトップエディタ。複数セッション、ファイル編集、チャットを1つのワークスペースで。

Download for macOS Windows Coming Soon Source Code

Features

>_

Multiple Sessions

最大4つのClaude Codeセッションを同時実行。2x2グリッドレイアウトで一覧性を確保。

</>

Built-in Editor

Monaco Editorを内蔵。CLIで生成されたファイルをクリックでそのまま開いて編集。

💬

Chat Mode

CLI表示とチャット表示をワンクリックで切替。同じセッションをデスクトップアプリライクに操作。

📎

Drag & Drop

画像やファイルをチャットにドロップ。@メンションでワークスペース内のファイルを参照。

⚡

Skills & MCP

登録済みのスキルとMCPサーバーを可視化。ワンクリックでスキル実行、MCP管理。

📖

Markdown Preview

Notionライクなプレビュー表示。編集モードとプレビューを切り替えながらドキュメント作成。
